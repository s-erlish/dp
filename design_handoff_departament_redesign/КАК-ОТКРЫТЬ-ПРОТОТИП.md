# Как открыть прототип

`file://` не годится: `support.js` подгружает React через fetch, а у файлового источника
origin равен `null`, и CORS обрывает загрузку. Страница остаётся с 370 узлами и нулём
видимого текста. Отдавать надо по HTTP.

```bash
cd /home/user/dp/design_handoff_departament_redesign
python3 -m http.server 8899 --bind 127.0.0.1 &
```

Дальше — `http://127.0.0.1:8899/Прототип departament (офлайн).dc.html` (имя закодировать).

Вариант «(офлайн)» — копия оригинала, у которой React, React-DOM и Babel берутся из папки
`vendor/` вместо `unpkg.com`. Интернет ему не нужен. Оригинал `Прототип departament.dc.html`
не тронут и лежит байт в байт как прислан; ему нужен доступ к `unpkg.com`.

Из headless-браузера:

```js
import { chromium } from 'playwright';
const b = await chromium.launch({
  executablePath: '/opt/pw-browsers/chromium-1194/chrome-linux/chrome',
  args: ['--no-sandbox'],
});
const p = await b.newPage({ viewport: { width: 760, height: 1000 } });
await p.goto('http://127.0.0.1:8899/' + encodeURIComponent('Прототип departament (офлайн).dc.html'));
await p.waitForTimeout(6000);   // React грузится и монтируется
await p.screenshot({ path: 'proto.png', fullPage: true });
```

Playwright ставится в скретчпад: `npm i playwright`. Chromium уже в образе, скачивать не надо.

Анимации снимаются покадрово: кликнуть по элементу, затем делать скриншоты по меткам времени.
Так проверяются тайминги из README §3 — например, что строки серверов выезжают с задержкой
700 мс плюс 85 мс на каждую.

Ошибки в консоли вида `{{ r.icon }}` и `{{ r.vb }}` — неразвёрнутые шаблоны в скрытых
`<template>`, они нормальны и ни на что не влияют.
