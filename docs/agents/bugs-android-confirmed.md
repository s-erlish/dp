The single defect list for the Android fixing wave. Read against the working tree at commit
`b5a113c` ("Salvage the foundation and restoration work stranded by the container restart"), branch
`claude/app-audit-agents-hyyftk`, 2026-07-26.

**Every line number below was re-resolved against today's source.** The salvage commit rewrote
`MainActivity.kt` (+463 lines), `menu_main.xml`, `FlagUtil.kt`, `SpeedtestManager.kt`, `HttpUtil.kt`,

Where an input document's claim no longer matches the source, the source wins and the divergence is
recorded in section 2 or 3 rather than dropped.
